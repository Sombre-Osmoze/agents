# Contributing to Agents Configuration Repository

Thank you for your interest in contributing to this project! This document provides guidelines and instructions for contributing.

## How to Contribute

### Adding New Agent Configurations

1. **Fork the repository** and create a new branch for your contribution
2. **Create your agent configuration** in the `agents/` directory
3. **Document your agent** with clear comments and usage instructions
4. **Test your configuration** to ensure it works as expected
5. **Submit a pull request** with a clear description of what your agent does

### Agent Configuration Guidelines

When creating agent configurations:

- **Be Specific**: Clearly define the agent's purpose and scope
- **Include Examples**: Provide usage examples in the `examples/` directory
- **Document Well**: Add comprehensive comments explaining the configuration
- **Follow Naming Conventions**: Use descriptive, lowercase names with hyphens (e.g., `python-linter-agent.md`)
- **Keep It Simple**: Focus on one clear purpose per agent

### File Structure

```
agents/
├── your-agent-name.md           # Agent definition
```

### Pull Request Process

1. Update the README.md if you're adding a new category of agents
2. Ensure your configuration follows the existing style and patterns
3. Include example usage in the PR description
4. Link any related issues or discussions

### Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the content, not the contributor
- Help others learn and grow

### Questions?

If you have questions about contributing, please open an issue with the `question` label.
