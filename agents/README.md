# Agent Configurations

This directory contains agent definition files that can be used with GitHub Copilot and other AI coding assistants.

## Available Agents

Browse the files in this directory to find agent configurations for different purposes.

## Using an Agent

To use an agent configuration:

1. Copy the agent file to your project's `.github/agents/` directory
2. Customize the configuration as needed for your project
3. Commit the changes to activate the agent

## Creating Custom Agents

Agent configurations are typically written in Markdown and include:
- A clear description of the agent's purpose
- Instructions for the AI to follow
- Context about the project or domain
- Examples of expected behavior

See the [examples](../examples/) directory for templates and examples.
